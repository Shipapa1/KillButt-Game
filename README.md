## Overview

**KillButt** is a rogue-like top-down shooter built in Unity. The game features fast-paced combat and retro-style visuals, where the player battles waves of enemies using a mix of melee and ranged weapons. Random item drops provide unique effects, helping the player survive increasingly difficult waves.

This was the first game project for our entire team, and we learned a lot as we developed it. Watching the game improve every week was incredibly rewarding!

---

## Game Features

### Gameplay:

- Survive against increasingly difficult waves of enemies.
- Start with basic stats and weapons, such as a sword, shotgun, sniper, and machine pistol.
- Complete random objectives and defeat enemies to boost your stats.
- Every 5 objectives, choose between battling bosses or continuing to scale difficulty.
- Defeat all bosses to win the game or continue playing indefinitely.

---

## Development Details

- **Game Engine:** Unity
- **Graphics & Assets:** Created using Gimp
- **Version Control:** Git & GitHub Desktop

### Game Logic & Features:

- Attack & Damage Interfaces for various enemy types.
- Enemy AI with different attack and movement patterns.
- Player mechanics, including health, attack stats, and weapon switching.
- Scaling difficulty system to increase enemy power over time.
- Loot system with randomized item effects.
- Interactive UI elements including health bars, objective trackers, and win/loss screens.

---

## Challenges & Lessons Learned

### Time Constraints:
- Certain features had to be cut, including:
  - Additional melee weapons
  - Loot drops from the environment
  - Multiple level designs

### Technical Hurdles:
- Unity version control caused issues with shared scenes, leading to frequent merge conflicts.
- We learned the importance of using tile-based map making to optimize performance.
